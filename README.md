# 📊 Churn Data Analytics

## 📌 Project Overview

Churn Data Analytics is a data analytics project focused on analyzing customer churn and identifying the major factors that influence customers to leave a service.

The project uses customer, subscription, and support-related data to generate meaningful insights and visualize churn patterns across different customer segments.

## 🎯 Objectives

- Analyze overall customer churn
- Identify factors affecting customer churn
- Compare churn across different plan types
- Analyze customer tenure and subscription behavior
- Study the relationship between customer support and churn
- Create meaningful visualizations and KPIs
- Generate insights that can help reduce customer churn

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- SQLite
- Jupyter Notebook
